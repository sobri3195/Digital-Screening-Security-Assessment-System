# Analisis ancaman dan kerentanan

Normalisasi domain, origin URL, IP, hash dan CVE. URL dengan kredensial, path khusus, query atau fragment ditolak. Kecocokan sumber berdasarkan nilai teknis identik. Teks hasil membedakan status engine antivirus dari kecocokan katalog. Ketika CVE hadir, CVSS, CWE, KEV, serta EPSS dan tanggal observasinya hanya muncul jika tertera pada metadata sumber. Kecocokan CVE tidak memastikan versi terdampak atau kompromi.
