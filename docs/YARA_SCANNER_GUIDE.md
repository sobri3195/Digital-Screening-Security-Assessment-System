# YARA

Instal ekstra `yara`, impor aturan lokal UTF-8 yang sudah ditinjau, dan beri nama serta versi. Aturan mulai nonaktif. Setelah diaktifkan, pilih YARA di modul Malware dan pilih file yang diotorisasi. Aturan dibatasi 64 KiB per kumpulan, maksimum lima kumpulan aktif, tanpa include. Pemindaian memakai file hingga 64 MiB dan batas waktu empat detik per kumpulan. Hasil menampilkan nama aturan, versi, checksum, waktu dan durasi tanpa menyimpan teks yang cocok dari file. Kecocokan membutuhkan peninjauan.
