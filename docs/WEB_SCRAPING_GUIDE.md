# Pemrosesan salinan advisori

Untuk BSSN dan Kemenkes, masukkan metadata secara manual atau unggah salinan resmi RSS/Atom atau HTML yang diotorisasi (maksimum 1 MiB). Parser DOM mengambil judul, ringkasan singkat, tanggal, dan rujukan. HTML harus memakai elemen `article` dengan judul dan paragraf, serta dapat berisi `time` dan tautan `rel=bookmark`. DTD dan input non-UTF-8 ditolak. Rujukan yang ada harus berada di domain organisasi yang dipilih.

Crawler online untuk penerbit advisori belum tersedia. Sebelum menambahkan adapter, pastikan persetujuan pengambilan data, robots.txt, ketentuan, dan hak cipta, serta prioritaskan feed resmi. Simpan hanya metadata yang diperlukan.
