# Privasi AI

Gateway hanya menerima skema teknis untuk analisis yang didukung. File mentah, prompt bebas, percakapan pribadi, akun, informasi medis, dan data biometrik berada di luar skema. Tugas menyimpan input teknis untuk riwayat dan deduplikasi. Audit menyimpan pseudonim aktor, operasi, status, waktu dan ID objek, tanpa isi prompt, token, atau jawaban. Otorisasi terpisah dibutuhkan untuk mengimpor materi teknis dan meninjau hasil milik aktor lain.

Gunakan enkripsi volume dan backup institusi. Terapkan penghapusan riwayat melalui menu AI Settings. Batasi akses operator ke file registry token dan SQLite.
