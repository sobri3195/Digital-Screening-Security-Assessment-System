# Laporan dan ringkasan pimpinan

Backend PHP menghitung aset terdaftar, insiden aktif, kandidat CVE kritis dan mitigasi terbuka dari snapshot saat permintaan. Hitungan pengamatan malware dapat dibatasi bulan atau tahun. Aplikasi menyisipkan angka tanpa mengambil angka dari respons model. Hasil menyertakan ringkasan, fakta, sumber, keterbatasan dan saran. Persetujuan petugas berbeda membuka PDF, sedangkan JSON tersedia sebagai keluaran terstruktur. Perbandingan historis penuh memerlukan skema agregasi periodik tambahan.
