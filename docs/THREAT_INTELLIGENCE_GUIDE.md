# Panduan Threat Intelligence

Gunakan Threat Scanner untuk mencocokkan URL, domain, IPv4, IPv6, MD5, SHA-1, SHA-256, dan CVE terhadap data lokal. Halaman URL, Domain, IP, Hash dan Phishing menyediakan masukan khusus. Phishing mengambil observasi dengan kategori phishing. Pemeriksaan File Fase 1 dapat menyerahkan SHA-256 lewat formulir lokal. Gunakan Intelijen Merek untuk menambahkan domain resmi dan memeriksa indikasi kemiripan berbasis jarak edit atau karakter. Hasil menyimpan tampilan defanged, dasar korelasi, dan snapshot bukti. Tidak menemukan kecocokan tidak membuktikan sebuah indikator aman.

Gunakan katalog untuk memfilter jenis, sumber, tanggal penarikan, status, dan keparahan; pilih rincian untuk bukti, verifikasi, atau pengarsipan. Gunakan Pusat Kerentanan untuk melihat sinyal CVSS, CISA dan EPSS, menghasilkan kandidat aset, menunjuk petugas, dan menetapkan tenggat institusi. Tenggat CISA tetap menjadi metadata sumber. Bookmark dan read status advisori bersifat per pengguna. Alert mendukung acknowledgment, penugasan, dan penyelesaian. Dashboard membedakan kartu dan grafik IOC yang mengikuti filter dari ringkasan seluruh katalog.

Laporan dapat dibuat dari snapshot katalog atau pemeriksaan milik pengguna. Setujui melalui supervisor lain. Halaman pratinjau mendukung cetak dan unduh PDF dengan kop, watermark internal, informasi sumber, dan keterbatasan hasil.
