# Asisten AI untuk web dan desktop

Pada web buka Artificial Intelligence lalu pilih jenis analisis. Dari rincian CVE Phase 2, pilih **Jelaskan CVE dengan AI** untuk mengisi ID CVE. Pantau tugas, periksa sitasi, dan tinjau hasil. Ekspor JSON kapan diperlukan. PDF terverifikasi hanya tersedia setelah review petugas lain.

Pada Device Inspector gunakan **AI Assistant**. Pilih gateway mandiri di loopback atau gateway pusat HTTPS dengan IP privat. Masukkan token workstation yang ditetapkan administrator, uji koneksi, pilih jenis analisis, isi metadata, lalu konfirmasikan pengiriman. Origin dan token berada di memori sesi aplikasi. Panel mengambil status dan riwayat atas permintaan operator. File, isi sesi pemeriksaan, dan identitas pemilik aset tidak diunggah.
