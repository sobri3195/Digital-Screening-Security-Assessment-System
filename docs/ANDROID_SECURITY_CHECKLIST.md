# Checklist Android

Gunakan aset institusi berjenis Android. Catat versi OS dan level patch dari Setelan atau laporan pengelolaan resmi. Periksa screen lock, enkripsi, Play Protect, pembatasan sumber tidak dikenal, USB debugging, pengelolaan institusi, backup, keamanan jaringan dan dukungan pembaruan. Setiap item menerima status dan catatan teknis. Pilih **Belum tersedia** saat kontrol tidak dapat diverifikasi.

Inspector tidak berinteraksi dengan ADB, tidak mengaktifkan debugging, dan tidak mengakses direktori privat. Laporan Android tersedia pada halaman Riwayat.
