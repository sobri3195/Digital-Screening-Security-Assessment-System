# Checklist iOS dan iPadOS

Gunakan pengaturan resmi atau laporan MDM institusi yang diotorisasi untuk memeriksa model, versi, pembaruan, passcode, update otomatis, backup, status pengelolaan, konfigurasi keamanan dan dukungan. Jika kontrol tidak terlihat, catat sebagai belum tersedia. Inspector tidak meminta isi perangkat atau backup, dan tidak menafsirkan keberadaan passcode sebagai verifikasi enkripsi.
