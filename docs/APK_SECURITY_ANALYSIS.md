# Analisis APK

Pilih berkas APK yang diserahkan secara sah. Inspector memvalidasi struktur dasar ZIP, membaca tepat satu manifest XML teks atau biner, menampilkan package, versi, SDK, izin dan SHA-256, lalu mencocokkan hash pada katalog lokal. Entri manifest dibatasi 1 MiB. Sertifikat JAR v1 dilaporkan sebagai metadata bila dapat dibaca. Signature v2/v3 dan trust chain belum divalidasi. APK tidak dipasang, dijalankan, atau diekstrak ke sistem. Deklarasi izin membantu triase teknis.
